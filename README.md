# 🌀 Truth & Dare: Spin the Bottle Edition

An interactive and fun **"Truth or Dare"** game featuring a spinning bottle mechanic! Spin the bottle, let fate choose *Truth* or *Dare*, and get a random prompt — perfect for parties or casual hangouts.

🎮 **Live Demo**: [Play Now](https://shashi1562.github.io/truth-dare)

---

## ✨ Features

- 🧭 **Spin-the-Bottle Mechanism**  
- 🎯 Select **Truth** or **Dare**  
- 📋 Random prompt displays in a popup  
- 🔁 **Rotate Again** to keep playing  
- 🎨 Clean, responsive design (mobile-friendly)  

---

## 🛠 Technologies Used

- **HTML**, **CSS**, **JavaScript** and  **Vue**
- Bottle spinning implemented with CSS transforms and JS randomization
- Hosted using **GitHub Pages**
